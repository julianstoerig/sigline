# sigline

Block-diagram simulation in plain Python: continuous, discrete and mixed
systems, built on NumPy and SciPy.

sigline is being rewritten from scratch. The goals and the design are in
[docs/design.md](docs/design.md). The first version is kept on the branch
[`v1`](https://github.com/julianstoerig/sigline/tree/v1), tagged
`first-version`; [docs/architecture.md](docs/architecture.md) describes it
and [docs/comparison.md](docs/comparison.md) compares it with Simulink,
PathSim and python-control.
